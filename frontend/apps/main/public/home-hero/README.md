# Homepage hero photo derivatives

These locally served images are responsive, uncropped-in-encoding derivatives of the cited Wikimedia Commons photographs. Each derivative preserves the source aspect ratio; the homepage applies responsive `object-fit: cover` cropping. Derivatives are distributed under CC BY-SA 4.0, with visible attribution and source/license links in the carousel.

- **New Epe road** — Photo by Joseph Slyboy. [Source page](https://commons.wikimedia.org/wiki/File:New_Epe_lagos_road.jpg) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.en). Original: 4032 × 3024.
- **Fish statue in Epe** — Photo by Kwadoskii. [Source page](https://commons.wikimedia.org/wiki/File:Fish_Statue_Epe.jpg) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.en). Original: 4980 × 2801.

Each image has 640px and 1280px-wide AVIF, WebP and JPEG versions. The JPEG files are fallbacks; AVIF/WebP are selected where supported. No attribution implies photographer endorsement.
