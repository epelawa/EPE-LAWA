# Homepage hero image sources

The homepage gallery contains **52 Epe photographs**: the existing ten selected Commons images plus 42 additional, individually licensed Commons photographs from the Epe, Nigeria category and its listed subcategories. The user-facing image is locally stored; modern browsers receive responsive 640px/1280px AVIF or WebP variants, with WebP as the broad-format fallback. Photos are not traced into SVG. No image is cropped during encoding; the approved square hero presentation uses CSS `object-fit: cover`.

The visible caption identifies the photo author and links to both the original Commons file page and that file’s license. Adapted CC BY-SA images remain attributed and are distributed under the same license. The gallery loads the first slide eagerly and only prefetches a small upcoming window when connection settings allow; it does not request all 52 images at once. Autoplay remains disabled for reduced-motion, Save-Data and constrained 2G connections.

The owner reports separate image/media rights from Lagos State Government; that claim is owner-provided and was not independently verified in this asset audit. Every image below is included under the individual Wikimedia Commons license shown.
