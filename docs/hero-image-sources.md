# Homepage hero image sources

The homepage carousel uses two local photographs not present in the previous 52-photo hero manifest. Both are from Epe and are individually licensed CC BY-SA 4.0. The image caption links to the author’s Commons source page and the license.

The source files are resized to 640px and 1280px wide AVIF, WebP and JPEG variants. The full source aspect ratio is preserved during encoding; the responsive hero uses CSS `object-fit: cover`, so the viewport crop changes with the device. The carousel loads the current photo eagerly and preloads only the next slide when the connection allows it. It skips autoplay and prefetch on reduced-motion settings, Save-Data, 2G, hidden tabs, or pointer hover. A pause/resume control is available to keyboard users and appears visually only on focus; no visible arrows, dots or counter are shown.

Because the photos are resized and re-encoded derivatives, they remain attributed and are distributed under CC BY-SA 4.0. No endorsement by the photographers is implied.
