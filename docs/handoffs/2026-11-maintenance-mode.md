# Maintenance mode rollout

This PR provides a server-side request gate in the main Next app and a primary-administrator control under Settings. The public boolean is read fresh from the database for each gated request. When opted in, any missing/invalid response or timeout fails closed with the maintenance response. Public page requests receive a no-store 503 with `Retry-After` and `noindex`; APIs and mutations receive a no-store JSON 503. `/admin` and its descendants retain their existing staff authentication. Only the maintenance illustrations, logo and Next static assets are exempt; this is not a database, Supabase API, direct asset, separate-host or previously cached content access-control system. Verify CDN behavior, alternate deployment URLs, static caches, direct database access, server actions and all configured hosts before relying on it as a security barrier. Never use it to protect private data.

The four original AI-generated illustrations were inspired by the supplied references and recolored for EPE LAWA. They are selected randomly per page response; selection may repeat. The page avoids JavaScript and works without animations.
