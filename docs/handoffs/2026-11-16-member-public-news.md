# Member and public news refinement

Signed-in readers visiting the news index are directed to the member Discover feed, carrying supported search and category filters; the page number resets because public and member feeds use different page sizes. Anonymous visitors keep the public newsroom. Shared article URLs and metadata remain canonical and unchanged. Authenticated story readers see a member reading header with Discover and Saved links, their existing mobile tabs, and the existing save/share/comment features; public chrome and the public news footer are suppressed in this view. A failed session check falls back to the public view and does not grant member actions.

The public newsroom received a restrained white editorial surface, explanatory copy, refined category chips, cards, thumbnails and spacing. No sample stories, subscriber claims or external assets were added. The newsletter remains disabled as requested. This is a visual refinement, not a claim that all earlier requested site-wide or additional layout redesign work is complete.

Verification: typecheck, build, and tests passed (304 Node tests passed, one skipped; 24 Vitest tests). All 36 browser smoke tests passed against a synthetic local Supabase fixture. Added tests cover signed-in index-to-Discover navigation, article member chrome and return link, anonymous article navigation, and member article overflow at 320/375/768/1024/1440 CSS px. The fixture does not verify live provider-backed sign-in, comment/save writes or production delivery; an initial selector in the new browser test matched the mobile nav instead of the public nav and was corrected before the successful run. No production writes.
