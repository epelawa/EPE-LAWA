# Modern reference UI audit

**References reviewed:**

- https://getquant.app/
- https://sckooly.app/

## Patterns carried into Epe Lawa

The references are not conventional corporate landing pages. They are product-led editorial experiences with a clear point of view, a strong visual hero, compact navigation, repeated section rhythm, numbered feature groups, proof/standards content, and a final conversion block.

The Epe Lawa homepage now adopts those patterns without copying their product claims or imagery:

- A dark, high-contrast hero with a single memorable statement, one primary newsroom CTA, and one app CTA.
- A product-style newsroom preview so visitors can see what Epe Lawa is before entering `news.epelawa.ng`.
- A gold marquee band for the publication values and local identity.
- Numbered sections (`/ 01` through `/ 06`) that create a guided narrative instead of a loose list of empty product modules.
- Three visual cards for the newsroom, public record, and local signal.
- A three-step “how it works” section.
- A dedicated editorial standards block.
- A responsive coverage list and work-with-us CTA.
- Mobile breakpoints that collapse the hero, cards, grids, and contact links without horizontal overflow.

## Deliberate differences

Epe Lawa does not claim live stories, audience counts, institutional partnerships, or app-store availability that have not been connected. The visual language is modern, but the copy remains honest and the newsroom remains a separate destination at `https://news.epelawa.ng`.
