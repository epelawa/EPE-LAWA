# Newsletter follow-up visual evidence

These four PNGs are retained as visual-review evidence for the newsletter availability UI. They show the unavailable sign-up page, unavailable unsubscribe page, and the shared footer card at mobile and desktop widths. They are not product assets, fixtures, or a substitute for automated behavior checks; the focused browser tests separately verify route content, links, and the absence of a newsletter submission form or success claim.

Git history shows all four files were introduced with the newsletter availability implementation in commit `7b5c1e7e00a062f5ea0601f8cc56e73176e4e704` on 2026-11-15 by `Akanji Mus'ab`. Their PNG metadata contains no capture URL, browser/version, or capture command, so the original capture environment cannot be independently established and is intentionally not asserted here.
